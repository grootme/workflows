# Project Docs - RiccoAgency

Estructura principal de la documentación del proyecto. Cada carpeta contiene archivos detallados listos para revisión y edición.

Carpetas:
- 01-strategy: Visión, modelo de negocio, roadmap
- 02-architecture: Arquitectura técnica, stack, despliegue
- 03-jarvis: Definición de Kaia, Elara, Zoe, Rhea, Nyx y sus roles
- 04-janus: Diseño del meta-asistente Janus y módulos asociados
- 05-mcp: Implementación del servidor MCP, especificaciones y ejemplos
- 06-use-cases: Casos de uso detallados y pasos de implementación
- 07-operations: Procesos, SLAs, soporte y plantillas operativas
- 08-legal-finance: Contratos (MSA, SOW), estructura financiera
- 09-marketing-sales: Estrategia de marketing, ventas y posicionamiento
- 10-templates: Plantillas (contratos, propuestas, checklists)
- 11-n8n-workflows: Ejemplos de workflows n8n importables y templates
- 12-infra: docker-compose, k8s manifests y scripts de despliegue

Siguientes pasos:
1. Revisar estructura y confirmar si deseas cambios en nombres de carpetas.
2. Poblar los archivos con contenido detallado (siguiente fase).
3. Revisar coherencia y unificar definiciones de roles (Kaia, Elara, etc.).

Para pedir que añada contenido en una carpeta específica, responde con: "Agregar contenido en <carpeta>" (por ejemplo: "Agregar contenido en 06-use-cases").
